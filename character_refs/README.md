# 曹蒹葭的参考照片

本仓库不包含参考照片。需要固定人物长相时，把你有权使用的照片放在本目录。
推荐放 2～3 张清晰、单人、光线均匀的不同角度照片，并命名为 `01_正面.png`、`02_侧面.png`、`03_半身.png`。

支持 `.jpg`、`.jpeg`、`.png`、`.webp`、`.bmp`，按文件名自然排序取前 `max_refs` 张。
上传前会按 `knowledge.toml` 中的 `ref_max_edge` 和 `ref_jpeg_quality` 压缩，默认长边 1536 像素。

照片已被 `.gitignore` 排除，不上传 GitHub。开启生图后，参考照片会发送给 `.env` 配置的图片服务商，用于生成图片。

可运行 `python image_service.py` 检查配置、参考图清单和提示词；该检查不调用生图接口。
